<b>Expressive Launcher 4.0.4 QA — Outside the Box</b>

Welcome to Expressive Launcher 4.0.4 (Build 53)! In 4.0.3, large folders sat atop the desktop. In this release, we've completely evolved large folders into true native <b>Folder Widgets</b> inspired by Hanks' app folder widget architecture. You can now resize folders freely across any cell layout, enjoy dynamic responsive column spacing (including tight 4x4 grids), customize backgrounds and styles with Expressive Pro, and morph between normal 1x1 folders and interactive widgets in a single tap.

───────────────────────

<b>✨ What's New & Improved</b>

1. <b>Native Interactive Folder Widgets</b>
• <b>Before:</b> Large folders were synthetic tiles that simulated widget layouts and sat over desktop cells.
• <b>Now:</b> Folder widgets are fully integrated Home widgets. They occupy true workspace grid cells, automatically push neighboring icons during resize via <code>CellLayout</code> space reservation, and never conflict or cause item overlap.
• Convert any standard 1x1 folder into a live widget with a single tap on <b>"Make widget"</b> in the long-press menu, or add new 2x2 folder widgets directly from the Widget Picker under Expressive Launcher.
• Easily revert to a standard 1x1 desktop folder at any time via <b>"Make normal folder"</b> or the open folder footer button.

2. <b>Responsive 4x4 & Multi-Column Layout Math</b>
• When resized to 4x4, apps now intelligently span across all 4 desktop columns, cutting out dead center clustering and keeping left/right side margins snug to native 8dp padding.
• Smaller widget spans dynamically select 2–3 columns matching content count, or you can pick your own column count (2 to 6).

3. <b>Clean Modern Aesthetics & Auto-Hidden Labels</b>
• Converting a folder to a widget automatically wipes any stale style and hides the bottom folder name label underneath the panel for a clean, distraction-free widget card.
• App labels inside the widget automatically adapt to vertical height, cleanly hiding on thin 1-row widget strips (like 2x1 or 3x1) so icons remain crisp and unclipped.

4. <b>Per-Widget Styling & Customization (Room Database v4)</b>
• Long-press any folder widget and tap the settings gear to open the dedicated <b>Folder Widget Settings Sheet</b>.
• Free controls: customize column layout (Auto or 2–6), toggle header visibility, and adjust app label displays.
• Expressive Pro controls: customize individual background colors, panel opacity, custom corner radii, and icon scaling.

5. <b>Fluid Morph Transitions & Native Gestures</b>
• Expanding and collapsing uses <code>RoundRectRevealAnimator</code>, smoothly morphing between the widget container bounds and the open folder panel without awkward intermediate states.
• Drag apps directly into or out of the widget with live grid reflow.
• Vertically scrollable when app contents exceed visible capacity, while non-scrolling widgets pass Home gestures (shade swipe down, app drawer swipe up) through cleanly.

6. <b>Full TalkBack & Accessibility Integration</b>
• Clear TalkBack descriptions ("Folder widget, [Name], [N] apps").
• Dedicated accessibility actions for resizing, converting to normal folder, and managing apps.
