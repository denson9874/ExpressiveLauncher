<b>Expressive Launcher 4.1.2 (Build 61) — Expressive Core & Stable Drawer Sizing</b>

Two major milestones in this release: introducing <b>Expressive Core</b> for frictionless browser installs on Android 15/16/17, and stabilizing app drawer icon sizing when exiting search. Thank you to our community contributors for reporting edge cases and testing!

<b>✨ What's New & Improved</b>

1. <b>Expressive Core Edition</b> (XDA-021):
• New lightweight build without Accessibility or Notification Listener services, specifically avoiding Google Play Protect's "Enhanced Fraud Protection" warning when sideloading from browsers.
• Built with the identical package name (<code>dev.launcher.expressive.l3</code>) and signing certificate, ensuring seamless upgrades between Full and Core builds.
• Core provides standard home launcher features with device-admin or root screen lock fallbacks.

2. <b>Stable Drawer Icon Sizing on Search Exit</b> (TG-011):
• Fixed an issue where app drawer icons remained enlarged after backing out of drawer search and only reverted to proper proportions upon closing and reopening the drawer.
• In <code>BubbleTextView</code>, <code>applyFromWorkspaceItem()</code> now synchronizes icon dimensions with the active <code>AllAppsProfile</code> across drawer displays (prediction rows and search shortcuts).
• In <code>ActivityAllAppsContainerView</code>, completing search dismissal explicitly notifies active drawer adapters to refresh visible views against active device profile dimensions.

3. <b>Dual-Variant QA Automation & CI Pipeline</b> (XDA-021):
• Jenkins pipeline now automatically compiles, verifies, seals, and distributes Expressive Core (<code>-PexpressiveCore=true</code>) alongside Full QA builds.
• Manifest scanner strictly validates that Core APKs contain no flagged permissions, and smoke tests verify upgrade compatibility between Full and Core releases.
