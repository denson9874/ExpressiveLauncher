<b>Expressive Launcher 3.0.8 — Discovery Unleashed</b>

Welcome to Expressive Launcher 3.0.8 (Build 40)! Today's milestone release brings automated Google Play publishing, our official dedicated Expressive Feed Companion, and a permanent resolution to package installer conflicts for seamless Google Discover integration.

───────────────────────

<b>✨ What's New & Fixed</b>
• <b>Google Play Store Rollout</b>: Fully configured and published via automated Google Play Developer API pipelines (<code>com.denson9874.Expressive_Launcher_L3</code>, Version Code 40).
• <b>Dedicated Expressive Feed Companion</b>: Under Google Play policies, store-distributed launchers cannot bundle private AIDL overlay services directly. We have introduced the official standalone companion app (<code>dev.launcher.expressive.feed</code>), lightweight and battery-friendly, bridging Google Discover to your home screen.
• <b>Android Package Conflict Resolved</b>: Fixed a critical Android security error (<code>INSTALL_FAILED_DUPLICATE_PERMISSION</code>) that previously caused the package installer to display <i>"App not installed"</i>. The companion APK now installs cleanly on all Android 12 through Android 17 devices.
• <b>Play Store Cryptographic Signature Verification</b>: Updated <code>FeedBridge</code> and <code>ExpressiveFeedSetup</code> with verified developer key hash (<code>2aa9f1bf3dbd2d5bd27ad7516f1caf1b8a18e15f6d59858a37282784bb2acba7</code>), eliminating the <i>"belongs to a different version"</i> warning and enabling the <b>Show Google Discover</b> toggle directly in Home Settings.
• <b>Streamlined Companion Release</b>: Cleaned up release assets on GitHub to eliminate confusion. There is now a single official file (<code>ExpressiveFeed.apk</code>) with an instant direct download and setup guide available on our <a href="https://denson9874.github.io/ExpressiveLauncher/feed/">GitHub Pages Feed Portal</a>.
