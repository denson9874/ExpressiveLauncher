Turn on Google Discover

The standalone Expressive Feed Companion is retired. Discover support now ships inside every Expressive release, so there's nothing extra to download. If Expressive sent you here from Download Expressive Feed Companion, follow these steps instead.

Installed the old companion? Uninstall it first: Android Settings > Apps > Expressive Feed > Uninstall. It was signed for the retired Google Play edition, can't connect to Expressive from GitHub, and blocks the built-in helper.
📲 Expressive 3.1.4 and earlier
  1. Let Expressive install its helper: Settings > Apps > Special app access > Install unknown apps > Expressive Launcher L3 > Always allow. You can change this back afterwards.
  2. In Expressive, open Home settings > Google Discover and tap Set up Google Discover. Tap Install when Android asks.
  3. If Google Play Protect shows App scan recommended, tap Scan app. When it reports This app looks safe, tap Install.
  4. Show Google Discover turns on. Swipe right from your first Home page.
✨ Coming in the next update

Set up Google Discover is always shown and asks for install permission itself. If the old companion is installed, settings offer Replace Discover support, which removes it and installs the built-in helper.
