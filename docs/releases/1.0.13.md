## Call Me by My Number 📞

**“Work” has officially resigned from being a phone number.**

This release fixes a contact-search mix-up: Call and Message actions now use the contact's saved
phone number. Custom labels and email addresses no longer audition for the dial pad.

### What's changed

- **The right number, even with a custom label.** A number labeled `Work` now opens the saved
  number. Previously, the label could become `967-5` in the dialer. Excellent spelling; terrible
  telecommunications.
- **Email stays out of the phone field.** Adding an email address no longer changes where the
  contact's phone actions lead. When several numbers exist, a marked default takes priority.
- **Useful results for contacts without numbers.** Email-only contacts still appear in search
  and open their details. Call and Message buttons appear only when there is a usable number.
- **Correct actions as results change.** Switching between contacts keeps the buttons and their
  accessible names matched to the current person.

### Checked before we called it a release

180 application tests, 104 pipeline tests and all 11 isolated device checks passed on Android 17
QPR2 Beta 4 (`CP41.260814.003.B1`). The published APK also completed a real 1.0.12 → 1.0.13 upgrade
through the launcher notification, verified download and Android installer on the test emulator.
The existing update job was expedited for that check.

The original install date, default Home role and enabled People-search/notification settings were
retained. Contact actions, an empty SMS composer and three cold Home launches passed, with no
observed crash or ANR. No test calls were placed and no messages were sent.
