# Expressive Launcher 4.1.1 (Build 60) — Consistent Sizing, Sleek Folders & Pro Trial

Three community-requested improvements delivered straight from our Telegram discussions. Thank you for the thoughtful feedback and bug reports!

### ✨ What's New & Improved

1. **7-Day Pro Free Trial** (TG-008):
   - You can now experience all Expressive Launcher Pro features free for 7 days with a single-device trial.
   - Start the trial directly from the Expressive Pro screen to test all premium customisation and gesture features risk-free.

2. **Stable Drawer Icon Sizing** (TG-009):
   - Fixed an issue where recycled app drawer views could experience icon size fluctuations when navigating in and out of the app list.
   - Drawer views now strictly synchronize their layout metrics and icon bounds against the active `AllAppsProfile` upon recycling and binding.

3. **Compact Open Folder Padding** (TG-010):
   - Tightened vertical margins and footer padding inside open folder views (reducing excess whitespace at the top and around the folder footer).
   - Folders look balanced and proportional across both 3-row and standard grid specs.
