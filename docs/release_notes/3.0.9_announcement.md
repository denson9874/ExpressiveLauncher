# Expressive Launcher 3.0.9 — Seamless Pro Activation & Polished Licensing

Welcome to Expressive Launcher 3.0.9 (Build 41)! This release delivers crucial enhancements to the Expressive Pro activation experience, introducing smart transaction validation, an offline support fallback flow, and 1-tap assistance for supporters.

### ✨ What's New & Fixed

- **Resilient Pro License Activation**: Resolved connection errors when verifying PayPal donations. Online verification timeouts and server maintenance states now gracefully fall back to our instant offline licensing path.
- **1-Tap Email Support for Offline Keys**: If automated online verification is temporarily unavailable, the Redeem Pro dialog now provides a 1-tap **"Email Support for Pro Key"** button that pre-populates your Device ID and Transaction ID directly to `daryldenson0405@gmail.com` for immediate key issuance.
- **Quick Copy Details Action**: Added a 1-tap **"Copy Details"** button so users can instantly copy their Device ID and transaction information to the clipboard for sharing on XDA, Telegram, or email.
- **Smart Input Detection & Safety Guards**:
  - **Donation Button ID Detection**: Detects if a user inadvertently enters the hosted PayPal button ID (`9RB3TYYQ6FWE2`) and provides clear instructions on where to find their 17-character PayPal receipt ID.
  - **License Key Auto-Redemption**: If an offline license key (`EXPR-PRO-...`) is pasted into the transaction verification field, the launcher automatically recognizes it and activates your Pro license immediately.
- **Corrected Placeholder Hint**: Updated the transaction field hint to specify the 17-character format from PayPal receipts (e.g. `5Y6345678A1234567`), eliminating confusion with donation link IDs.
- **Always-Visible Support Card**: The *Donate & Unlock* tab now features a dedicated support card ensuring paying supporters always have a clear, immediate way to reach developer assistance.
