# Expressive Launcher 3.0.8 — Discovery Unleashed

Welcome to Expressive Launcher 3.0.8 (Build 40)! Today's milestone release brings automated Google Play publishing, our official dedicated Expressive Feed Companion, and a permanent resolution to package installer conflicts for seamless Google Discover integration.

---

### ✨ What's New & Fixed

- **Google Play Store Rollout**: Fully configured and published via automated Google Play Developer API pipelines (`com.denson9874.Expressive_Launcher_L3`, Version Code 40).
- **Dedicated Expressive Feed Companion**: Under Google Play policies, store-distributed launchers cannot bundle private AIDL overlay services directly. We have introduced the official standalone companion app (`dev.launcher.expressive.feed`), lightweight and battery-friendly, bridging Google Discover to your home screen.
- **Android Package Conflict Resolved**: Fixed a critical Android security error (`INSTALL_FAILED_DUPLICATE_PERMISSION`) that previously caused the package installer to display *"App not installed"*. The companion APK now installs cleanly on all Android 12 through Android 17 devices.
- **Play Store Cryptographic Signature Verification**: Updated `FeedBridge` and `ExpressiveFeedSetup` with verified developer key hash (`2aa9f1bf3dbd2d5bd27ad7516f1caf1b8a18e15f6d59858a37282784bb2acba7`), eliminating the *"belongs to a different version"* warning and enabling the **Show Google Discover** toggle directly in Home Settings.
- **Streamlined Companion Release**: Cleaned up release assets on GitHub to eliminate confusion. There is now a single official file (`ExpressiveFeed.apk`) with an instant direct download and setup guide available on our [GitHub Pages Feed Portal](https://denson9874.github.io/ExpressiveLauncher/feed/).
