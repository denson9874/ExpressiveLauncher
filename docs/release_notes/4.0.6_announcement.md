# Expressive Launcher 4.0.6 (Build 55)

### ✨ What's New & Improved

- **App Drawer Icon Scaling**: Fixed app screen icon size slider not applying on devices with responsive grid (Pixel handhelds and foldables). Icons now scale cleanly with their surrounding cell height expanding smoothly to prevent downscaling or clipping.
- **App Drawer Horizontal Padding**: Fixed drawer horizontal padding slider calculation on responsive grids, replacing the legacy 100x multiplier with smooth 1:1 proportional scaling.
- **Tab Strip & Header Alignment**: Fixed `FloatingHeaderView` tab strip insets so Personal and Work profile tabs align precisely with app drawer columns without double padding.
