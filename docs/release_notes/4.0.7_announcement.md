# Expressive Launcher 4.0.7 (Build 56)

### ✨ What's New & Improved

1. **App Drawer Style Choice (Full-Screen vs Bottom Sheet)**:
   - Added user setting (**Settings → App Drawer → General → Bottom sheet drawer**) letting users choose between the default edge-to-edge full-screen App Drawer and the classic Pixel Launcher floating bottom sheet presentation.
   - Enabling the bottom sheet restores the top drag handle pill (`—`) and subtle background wallpaper scaling while preserving smooth edge-to-edge column spacing.

2. **Folder Widget Closing Animation Polish**:
   - Reworked the closing animation when collapsing the expanded full folder view back into its Home folder widget.
   - Smoothly cross-fades the folder panel into the resting widget tile during the final transition, eliminating visual edge clipping and the flash artifact where the folder briefly popped back up in the center of the screen.

3. **Android Developer Verification & Play Protect Clearance**:
   - Integrated automated developer identity and certificate validation for off-Play build distributions (GitHub Releases & Obtainium) targeting Google Play Console Android Developer Verification (Developer ID `5547708187557586870`).
   - Ensures standalone packages clear Play Protect developer accountability checks.
