# Expressive Launcher 4.1.2 (Build 61) — Expressive Core & Stable Drawer Sizing

Two major milestones in this release: introducing **Expressive Core** for frictionless browser installs on Android 15/16/17, and stabilizing app drawer icon sizing when exiting search. Thank you to our community contributors for reporting edge cases and testing!

### ✨ What's New & Improved

1. **Expressive Core Edition** (XDA-021):
   - New lightweight build without Accessibility or Notification Listener services, specifically avoiding Google Play Protect's "Enhanced Fraud Protection" warning when sideloading from browsers.
   - Built with the identical package name (`dev.launcher.expressive.l3`) and signing certificate, ensuring seamless upgrades between Full and Core builds.
   - Core provides standard home launcher features with device-admin or root screen lock fallbacks.

2. **Stable Drawer Icon Sizing on Search Exit** (TG-011):
   - Fixed an issue where app drawer icons remained enlarged after backing out of drawer search and only reverted to proper proportions upon closing and reopening the drawer.
   - In `BubbleTextView`, `applyFromWorkspaceItem()` now synchronizes icon dimensions with the active `AllAppsProfile` across drawer displays (prediction rows and search shortcuts).
   - In `ActivityAllAppsContainerView`, completing search dismissal explicitly notifies active drawer adapters to refresh visible views against active device profile dimensions.

3. **Dual-Variant QA Automation & CI Pipeline** (XDA-021):
   - Jenkins pipeline now automatically compiles, verifies, seals, and distributes Expressive Core (`-PexpressiveCore=true`) alongside Full QA builds.
   - Manifest scanner strictly validates that Core APKs contain no flagged permissions, and smoke tests verify upgrade compatibility between Full and Core releases.
