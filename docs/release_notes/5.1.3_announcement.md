# Expressive Launcher 5.1.3 (Build 75) — Hold to Search

5.1.3 is a one-fix update for ExpressiveOS. Circle to Search now works from Expressive Launcher: touch and hold the navigation handle to search what's on your screen. Phones that don't run Expressive Launcher as a built-in system app see no change.

---

### ✨ What's New & Improved

#### 1. 🔍 Circle to Search from Expressive Launcher
- **Before**: on ExpressiveOS, holding the navigation handle did nothing while Expressive Launcher was your launcher. The launcher never asked Android for the permission that starts Circle to Search, so it stopped before trying.
- **Now**: the launcher asks for it. Android only grants it to a launcher built into the system with an allowlist entry, which ExpressiveOS 1.1.2 adds. On other phones Android doesn't grant it, and the launcher behaves exactly as before.
