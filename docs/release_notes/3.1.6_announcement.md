# Expressive Launcher 3.1.6 QA — Search and Ye Shall Find

Welcome to Expressive Launcher 3.1.6 (Build 48)! Settings search used to answer "No widgets or shortcuts found" when you asked it for a setting. This build teaches it to find every setting, walk you to the row and knock twice.

---

### ✨ What's New & Improved

1. **Settings search finds every setting**
   - **What went wrong:** the search list was a short hand-written set of English phrases that had drifted from the screens. Typing *return*, *suggestions in dock*, *status bar*, *Discover* or *rotation* found nothing or the wrong thing, and an empty result said "No widgets or shortcuts found" (the widget picker's message). It even listed settings Expressive doesn't have.
   - **Now:** about 150 settings are searchable, in your language, and each result opens the screen it lives on. The best match comes first: an exact title, then titles that start with your words, then the rest. Accents and capitals don't matter, and every word you type has to match.
   - The search box now says **Search settings** and an empty result says **No matching settings**.

2. **Search takes you to the setting**
   - Choose a result and the screen scrolls to that row, with its neighbours in view, and pulses it twice so you can spot it.
   - Options hidden behind an Expressive Pro lock stay hidden; you land on the lock card.

3. **TalkBack can name Settings' icon buttons**
   - Back, **Search settings**, **More options**, **Clear**, copy, paste, reset and download buttons were all announced as just "Button". They now say what they do, and any new icon button has to carry a label.

4. **One less switch that did nothing**
   - **Live information** in *Icons & appearance* promised announcements and default feature flags, but Expressive never fetched or showed either. The switch and the empty **Updates** heading above it are gone.

5. **Clearer Discover setup**
   - If Android answers "App not installed" because an old Expressive Feed is still hiding in Private space or a work profile, the message now names that as the likely cause. Android hides that copy from apps, so this can only be explained after the attempt.

### 🗣️ From Your Reports

- **Finding settings** (the navigation and discoverability threads): search is now a dependable way in, and it takes you to the row instead of to the top of a long page.
- **Return to default page (XDA-015):** we re-tested this on 3.1.5. With the switch off, opening an app from page 2 and coming back with Back or Home leaves you on page 2. With it on (the default, as on Pixel), you return to page 1. No change needed.
