# Expressive Launcher 4.0.0 Stable — Type Less, Find More

Welcome to **Expressive Launcher 4.0.0 Stable** (Build 49), the first stable release since 2.0.8 and our first major release since 3.0. Stable users are getting the headline 4.0 changes plus everything from the 22 builds released since 2.0.8. The app drawer search now behaves like Pixel's, Home does a lot less unnecessary work, Discover works again, and there's a lot more in between.

---

### 🏗️ The work behind this release

Stable only moves when the QA channel has proved a change. Here's what went into this one:

- **22 builds shipped** between 2.0.8 Stable (Build 26) and this release, from 2.0.8 Hotfix 1 (Build 27) to 3.1.6 (Build 48), 18 of them as public QA releases, plus the 4.0.0 candidate itself.
- **70 commits** of product work: 268 files changed, about 15,400 lines added and 1,700 removed.
- **7 GitHub issues fixed** (#17, #18, #19, #21, #22, #23, #24) and **8 XDA reports acted on** (XDA-003, -004, -006, -007, -008, -010, -012, -013).
- **Automated tests grew from 237 to 381** app unit tests (+144). The release-pipeline contract tests now number 288, including new checks that only exact, fully tested APKs can be sealed for release.
- **Five public pull requests** (#29–#33) were reviewed by independent agents, unit-tested and checked on the Android 17 QPR2 emulator before being ported into 4.0.0. A dedicated review pass (#33) found and fixed four problems in them before any user saw them.
- **Every build in this history** went through Jenkins: full unit suite, signature and packaging checks, and an isolated emulator upgrade test before publication.

Details of the testing for this build are under **🧪 Validation** below.

### 🌟 New in 4.0.0

1. **Pixel-style drawer search**
   - Results appear as you type. Each section keeps its rows until its new answers arrive, so going from *wea* to *weat* doesn't make the list jump.
   - The search pill stays solid while you're using it.
   - Closing the search (clear, Back or closing the drawer) starts the next one fresh. Old results can't sneak in.
   - The Pixel Search provider is now labelled **Pixel Search (third-party)**, to be clear it isn't Google's own.
2. **Enter searches the web.** Enter on a query with no matching app opens your web search. It used to be able to open a Play Store search while suggestions were loading.
3. **A calculator that knows when it's needed.** Calculator results are on by default: type *12\*7* and 84 is at the top. It only answers real calculations, so *e*, *2024* or *pi* no longer get a calculator row. `sqrt()` works too.
4. **Smoother Home and app transitions**
   - Home no longer clears a blur that's already clear, or writes a log line on every animation frame.
   - Home no longer reloads every app and icon each time it's recreated, only when an icon pack or themed icon pack needs it.
   - App suggestion rows stop re-binding every time you return to Home or open the drawer.
5. **Labels follow your language.** Change the system language and Home and drawer labels, plus the drawer's section letters, switch right away instead of after a restart.

### 📦 Since 2.0.8 Stable (released in QA along the way)

#### Search and settings
- **Settings search finds every setting**, in your language, with the best match first. Choosing a result scrolls to the row and pulses it (3.1.6).
- **TalkBack labels** for Back, Search, More options and the other icon buttons in Settings (3.1.6).
- **Scroll hints** on long settings pages, and an opens-elsewhere icon on rows that hand off to Android settings (3.1.3, XDA-007/-008/-013).
- Removed settings that did nothing: the Live information switch and redundant widget rows (3.1.6, 2.0.8 Hotfix 1).

#### Home, dock and drawer
- **Android 17 QPR2 home menu:** long-press Home for one wallpaper-tinted card with filled icons and your current and recent wallpapers (3.1.5).
- **Google search bar switch:** put the Google app's own dock search bar on Home, with Lens, voice and AI Mode, as on Pixel. It's opt-in (3.1.5).
- **Suggestions in dock** switch; with it off, empty dock spots stay empty (3.1.4, XDA-004).
- **Solid status bar background** option on Home, with light icons (3.1.4, XDA-010), and a Dock row in Home screen settings (3.1.4, XDA-012).
- **Folders match your app icon shape**, keeping any folder shape you picked yourself (3.1.3, XDA-006).
- **Recently installed apps** in drawer suggestions, and separate switches for drawer suggestions and the search bar (3.1.0, #21).
- **Home screen shortcuts:** edit their icon and label (#19); app drawer icon option and direct shortcuts (#17).

#### Google Discover
- **Discover works again.** Setup always installs the helper built into Expressive, **Replace Discover support** swaps out the old companion that couldn't connect, and the setup text explains what Android and Play Protect will ask (3.1.5).
- If Android answers "App not installed" because an old helper is hiding in Private space or a work profile, Expressive now says so (3.1.6).

#### Fixes
- QuickSwitch/Quickstep crash on Android 17 (`createInputConsumer`) fixed (3.1.1, #24).
- Crash when dragging shortcuts fixed, and returning to the default page fixed (#18, #23).
- Software rendering now protected against hardware icon bitmaps.
- Infinite scrolling setting now kept in Home screen settings.

#### Updates and distribution
- **Obtainium 1-click updates** from Settings > About, with F-Droid / IzzyOnDroid metadata in the repository (3.1.2, #22).

### ⚙️ Changes to know about when coming from 2.0.8

- **Expressive Pro arrived in 3.0.** Deep customization options (such as grid sizing, typography, gestures, per-app icon overrides and folder styles) now need a one-time $4.99 Pro activation. **Customizations you already made keep working after the upgrade.** Pro is only needed to change those options. Everything else stays free.
- **"Always reload icons" is now off** if you never changed it. If you turned it on yourself, it stays on. You can turn it back on in Experimental features if your icon pack updates often.
- **Calculator results in drawer search are now on.** You can turn them off in the drawer search settings.
- **Discover support is FOSS-only:** the separate Play-signed Feed Companion is retired. Use **Set up** or **Replace Discover support** in Discover settings.

### 🐞 Known issues

- Pressing Enter within a few milliseconds of the last letter may be ignored. Press it again.
- The *Search on Google* row can flash a Play Store icon for a couple of frames.
- Empty cards can appear for about 0.2 s when a new search first shows results.
- A hardware keyboard's Enter can start the web search twice.
- After a language change, some drawer icons can lose their TalkBack description until the next restart.
