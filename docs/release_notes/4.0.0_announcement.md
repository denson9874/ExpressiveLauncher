# Expressive Launcher 4.0.0 QA — Type Less, Find More

Welcome to Expressive Launcher 4.0.0 (Build 49), our first major release since 3.0! The app drawer search now behaves like Pixel's: results show up as you type and stay put while the next ones arrive. Behind the scenes, Home stopped doing a lot of work it never needed to do.

---

### ✨ What's New & Improved

1. **Pixel-style drawer search**
   - **Before:** every letter cleared the results and rebuilt them, so rows jumped around while you typed, and the search pill could fade out while you were using it.
   - **Now:** results appear as you type. Each section keeps its rows until its new answers arrive, so typing *wea* → *weat* doesn't make the list jump. The search pill stays solid while it has focus.
   - When you close the search (clear, Back or closing the drawer), the next search starts fresh. Old results can't sneak into it.
   - The Pixel Search provider is now labelled **Pixel Search (third-party)**, to be clear it isn't Google's own.

2. **Enter searches the web**
   - Pressing Enter on a query with no matching app opens your web search. Before, it could open a Play Store search while web suggestions were still loading.

3. **A calculator that knows when it's needed**
   - **Calculator results are now on by default.** Type *12\*7* and the answer, 84, is at the top.
   - It only answers real calculations (a number plus an operator or function), so *e*, *2024* or *pi* no longer get a calculator row. `sqrt()` works too.

4. **Smoother Home and app transitions**
   - **Blur:** Home no longer clears a workspace blur that's already clear, or writes a log line on every animation frame.
   - **No full reload on return:** Home no longer reloads every app and icon each time it's recreated. It reloads only when an icon pack or themed icon pack needs it.
   - **Suggestions:** app suggestion rows stop re-binding every time you come back to Home or open the drawer.

5. **Labels follow your language**
   - Change the system language and the Home and drawer labels and the drawer's section letters switch right away. Before, they kept the old language until a restart.

---

### ⚙️ Default changes

- **"Always reload icons" is now off** for everyone who never changed it. If you turned it on yourself, it stays on. Turn it back on in Experimental features if your icon pack updates often.
- **Calculator results are now on.** You can turn them off in the drawer search settings.

---

### 🐞 Known issues

- Pressing Enter within a few milliseconds of the last letter may be ignored. Press it again.
- The *Search on Google* row can flash a Play Store icon for a couple of frames.
- When a new search first shows results, empty cards can appear for about 0.2 s.
- A hardware keyboard's Enter can start the web search twice.
- After a language change, some drawer icons can lose their TalkBack description until the next restart.
