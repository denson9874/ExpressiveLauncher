# Expressive Launcher 5.2.0 QA (Build 83) — Material 3 Expressive Cohesion Across Every Surface

5.2.0 aligns Expressive Launcher end-to-end with the ExpressiveOS 2.0 Material 3 Expressive design system—unifying segmented `24dp`/`4dp` geometry, Google Sans Flex optical sizing, `28dp` bottom sheets, WCAG 2.2 AA frosted glass contrast, outcome-gated discrete haptics, and full Reduced Motion compliance across Settings, Workspace popups, Folders, Widgets, Search, and Recents.

---

### ✨ What's New & Improved

#### 1. 🎨 Material 3 Expressive Settings Dashboard & Typography
- **Before**: clean installs fell back to `ColorStyle.TonalSpot`, preference groups used `16dp` outer / `0dp` inner corners separated by `3dp` `HorizontalDivider` hairlines, `displaySmall` / `headlineSmall` mapped to `.Large` optical font axes, and discrete sliders fired `DRAG_INDICATOR_DISCRETE` on every sub-step drag pixel.
- **Now**: clean installs of the `expressive` flavor default to `ColorStyle.Expressive` via `config_default_color_style`; every `PreferenceGroup`, `LazyColumnPreferenceGroup`, `ReorderablePreference`, and dashboard card uses segmented `24dp` outer / `4dp` inner `surfaceContainer` geometry with `2dp` (`ListItemDefaults.SegmentedGap`) spacing and zero hairline dividers; `displaySmall` and `headlineSmall` bind to Google Sans Flex `.Small` optical families; and sliders emit discrete MSDL ticks strictly when crossing snapped steps while rendering value readouts with tabular numerals (`tnum`).

#### 2. 🧩 Segmented Workspace Shortcut Popups, `28dp` Sheets & WCAG Frosted Glass
- **Before**: multi-row `deep_shortcut_container` and `system_shortcut_rows_container` popups left inner rows un-segmented with `0dp` gaps, opened with `PathInterpolator` curves, used `72%` (`alpha = 184`) frosted glass pieces, and rendered `24dp` dialog/sheet corners.
- **Now**: `ArrowPopup` segments multi-row app and system shortcut wrappers into `24dp` outer / `4dp` inner cards with `2dp` transparent gaps prior to arrow orientation, opens with `SpringAnimationBuilder` (`stiffness = 420f`, `damping = 0.72f`), raises `BackdropGlass` piece alpha floors to `78%` light / `82%` dark for WCAG 2.2 AA contrast, and upgrades `ComposeBottomSheet` and `WidgetsFullSheet` to `28dp` top corners with pill search bars and tonal pill actions.

#### 3. ⚡ Pill Search, Folders, Recents Overview Actions & Reduced Motion Compliance
- **Before**: All Apps search groups used `20dp` outer corners and `12dp` header pills, `overview_action_button_background_blur` used a `54%` scrim without tactile press physics, and several animator paths (`Folder`, `ArrowPopup`, `AbstractSlideInView`, `AllAppsSearchInput`, `LawnQsbUi`, `ExpandAndShrink`, `MainSwitchPreference`) continued running transitions when `ANIMATOR_DURATION_SCALE == 0f`.
- **Now**: search groups use `24dp`/`4dp` segmented cards with `100dp` header pills and spring padding transitions; Recents action pills use `1000dp` stadium radii, WCAG-compliant `80%`/`84%` frosted scrims, `GSF_LABEL_LARGE` typography, spring press-scale (`0.94f -> 1.0f`), and `MSDLToken.TAP_MEDIUM_EMPHASIS` haptics; and all launcher, folder, popup, sheet, search, and Compose preference transitions snap cleanly when `ValueAnimator.areAnimatorsEnabled()` is `false`.
